# Feedback form

Самостоятельная работа по основам серверной веб-разработки. Автор: Доненко Татьяна Александровна, группа 253-325.

## Опубликованный сайт
https://tania-feedback.rf.gd/

HTTP-заголовки: https://tania-feedback.rf.gd/headers.php

## Запуск
Нужны PHP 8.x, расширение OpenSSL, доступ сервера в интернет и allow_url_fopen=On.
В папке проекта выполните:

```sh
php -S 127.0.0.1:8080
```

Откройте http://127.0.0.1:8080/index.php. Двойной щелчок по PHP-файлу не запускает сервер.

## Файлы
- index.php — форма с прямой отправкой POST на https://httpbin.org/post.
- headers.php — вызов get_headers('https://httpbin.org/get', false, $context), HEAD-запрос и вывод результата в readonly textarea. Обработка недоступности сервера и экранирование HTML.
- assets/ — общий CSS, проверка вариантов ответа на JavaScript и официальный логотип.

Для отправки выберите хотя бы один checkbox. При выборе СМС появляется обязательный номер телефона. Учебная форма отправляет данные стороннему httpbin: используйте вымышленные данные. Форма не отправляет настоящие СМС или письма — только передаёт выбранные варианты.

## Публикация
Загрузите index.php, headers.php и папку assets в публичный каталог PHP-хостинга (обычно public_html, www или htdocs). Нужен хостинг с PHP, а не GitHub Pages. Проверьте обе страницы по HTTPS после загрузки.

Для нового пустого репозитория GitHub:
```sh
git remote add origin https://github.com/ACCOUNT/feedback-form.git
git push -u origin main
```
Замените ACCOUNT на свой логин. Не добавляйте в репозиторий пароли хостинга и токены.

## Проверка
1. Пустая форма не отправляется. Некорректный e-mail блокируется браузером.
2. Без варианта ответа отправка блокируется; можно выбрать оба варианта.
3. СМС включает обязательное поле телефона; при отключении СМС поле не отправляется.
4. После отправки httpbin возвращает JSON с полями form, включая reply[].
5. Вторая страница показывает HTTP-заголовки сервера; обновление повторяет реальный запрос.
6. На узком экране поля располагаются в одну колонку.
